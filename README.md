# মাকতাব আল হিদায়াহ (Maktab Al Hidayah)

> **কুরআন ও সহিহ সুন্নাহর আলোকে ইসলামের শিক্ষা**  
> *"আমাদের কথা নয়—দলীলের কথা"*

---

## ভূমিকা ও পরিচিতি

**মাকতাব আল হিদায়াহ** একটি আধুনিক, রেসপনসিভ ও ডেটা-ড্রাইভেন ইসলামিক শিক্ষা ও দাওয়াহ প্ল্যাটফর্ম। এই প্ল্যাটফর্মের সমস্ত কনটেন্ট (বই, প্রবন্ধ, অডিও, ভিডিও, পাম্ফলেট, কোর্স ও প্রশ্নোত্তর) সম্পূর্ণ ডেটা-ফাইল (`.json`) দ্বারা পরিচালিত।

**সবচেয়ে গুরুত্বপূর্ণ নীতি:**
ওয়েবসাইটে নতুন কনটেন্ট যুক্ত করার জন্য কোনো HTML পেজ তৈরি বা কোডিং জানার প্রয়োজন নেই। শুধুমাত্র নির্দিষ্ট ফোল্ডারে ফাইল রেখে সংশ্লিষ্ট JSON ফাইলে একটি এন্ট্রি যোগ করলেই ওয়েবসাইট স্বয়ংক্রিয়ভাবে তা প্রদর্শন করবে।

---

## অফিসিয়াল লোগো যুক্ত করার নিয়ম (Logo)

অফিসিয়াল লোগোটি নিচের নির্দিষ্ট লোকেশনে রাখুন:
```
/assets/images/logo.png
```
*(অথবা Vite বিল্ডের জন্য `public/assets/images/logo.png` এ রাখুন)*

* **লোগো ফাইল আপলোড না থাকলে:** ওয়েবসাইট একটি মার্জিত ও পরিচ্ছন্ন ইসলামিক টেক্সট ব্যাজ দেখাবে।
* **লোগো ফাইল রাখলে:** ওয়েবসাইট স্বয়ংক্রিয়ভাবে কোনো বিকৃতি (distortion) ছাড়াই সঠিক অনুপাত বজায় রেখে লোগোটি প্রদর্শন করবে।

## ১. কীভাবে একটি নতুন বই যুক্ত করবেন (How to add a book)

### ধাপ ১: PDF ফাইল রাখুন
বইটির PDF ফাইলটি রাখুন:
`/assets/books/your-book-name.pdf`  
*(বা `public/assets/books/your-book-name.pdf`)*

### ধাপ ২: `data/books.json` এ এন্ট্রি যোগ করুন
`data/books.json` (এবং `public/data/books.json`) ফাইলটি খুলুন এবং তালিকায় নিচের মতো একটি অবজেক্ট যুক্ত করুন:

```json
{
  "id": "book-004",
  "title": "কিতাবুত তাওহীদ",
  "englishTitle": "Kitab at-Tawheed",
  "type": "book",
  "topic": "tawheed",
  "subtopic": "একত্ববাদ",
  "author": "শায়খুল ইসলাম মুহাম্মাদ বিন আব্দুল ওয়াহহাব (রহ.)",
  "publisher": "মাকতাব আল হিদায়াহ",
  "pages": 180,
  "language": "বাংলা",
  "description": "তাওহীদের বিশদ বিবরণ এবং শিরকের সূক্ষ্ম প্রকারভেদ থেকে বেঁচে থাকার প্রামাণ্য গ্রন্থ।",
  "thumbnail": "",
  "file": "/assets/books/kitabut-tawheed.pdf",
  "url": "",
  "keywords": ["তাওহীদ", "শিরক", "একত্ববাদ", "উলুহিয়্যাহ"],
  "tags": ["আকীদাহ", "প্রামাণ্য কিতাব"],
  "relatedTopics": ["aqeedah"],
  "references": [
    {
      "title": "কুরআন ও সহিহ হাদীস",
      "source": "মূল গ্রন্থ"
    }
  ]
}
```

সংরক্ষণ করে GitHub-এ পুশ করলেই বই লাইব্রেরি, তাওহীদ বিষয়ক পেজ এবং সার্চ রেজাল্টে বইটি স্বয়ংক্রিয়ভাবে দৃশ্যমান হবে।

## ৪. কীভাবে একটি ইউটিউব ভিডিও যুক্ত করবেন (How to add a YouTube video)

কোনো ভিডিও ফাইল আপলোড করতে হবে না। শুধুমাত্র ইউটিউব ভিডিওর লিংক দিয়ে `data/videos.json` ফাইলে এন্ট্রি যোগ করুন:

```json
{
  "id": "video-003",
  "title": "সহিহ নিয়মে সালাত আদায় করার পদ্ধতি",
  "type": "video",
  "topic": "salah",
  "subtopic": "নামাজ শিক্ষা",
  "speaker": "উস্তায আহমাদ",
  "duration": "৩৫:১৫",
  "description": "তাকবীরে তাহরীমা থেকে সালাম পর্যন্ত প্রামাণ্য হাদীসের আলোকে সালাতের সঠিক রূপরেখা।",
  "youtubeUrl": "https://www.youtube.com/watch?v=EXAMPLE_ID",
```

ওয়েবসাইট স্বয়ংক্রিয়ভাবে ভিডিওর আইডি বের করে রেসপনসিভ প্লেয়ার এবং থাম্বনেইল তৈরি করবে।

## ৮. কীভাবে নতুন বিষয় যুক্ত করবেন (How to add a new topic)

`data/topics.json` এ নতুন একটি বিষয় যোগ করুন:

```json
{
  "id": "zakat",
  "name": "যাকাত ও সাদাকাহ",
  "arabic": "الزكاة والصدقات",
  "english": "Zakat",
  "icon": "HeartHandshake",
  "description": "ইসলামের অন্যতম রুকন যাকাতের বিধান, নিসাব এবং সাদাকাহ সংক্রান্ত প্রামাণ্য আলোচনা।",
  "order": 9
}
```
এটি যোগ করলেই হোমপেজের "ইসলাম শিখুন" গ্রিডে এবং প্রতিটি লাইব্রেরির ফিল্টারে এটি তৎক্ষণাৎ যুক্ত হয়ে যাবে!

## ৯. অভ্যন্তরীণ সার্চ কীভাবে কাজ করে (How search works)

* সার্চ ব্যবস্থাটি **সম্পূর্ণ স্থানীয় (Local)**।
* এটি গুগল বা ইন্টারনেটে কোনো সার্চ করে না।
* এটি কোনো কৃত্রিম বুদ্ধিমত্তা (AI) ব্যবহার করে মনগড়া তথ্য তৈরি করে না।
* এটি কেবল আপনার সংরক্ষিত `books.json`, `articles.json`, `pamphlets.json`, `audios.json`, `videos.json`, `courses.json`, `qna.json` এবং `topics.json` ফাইলের ফিল্ডসমূহ (title, description, topic, keywords, relatedKeywords, author, speaker, references) অনুসন্ধান করে ক্যাটাগরিভিত্তিক রেজাল্ট প্রদান করে।

## ১০. ডেটা-গ্রাউন্ডেড প্রশ্নোত্তর নিরাপত্তা নীতি (How Q&A works)

* প্রশ্নোত্তর অনুসন্ধানটি শুধুমাত্র ওয়েবসাইটের সংরক্ষিত ও যাচাইকৃত তথ্যের মধ্যে সীমাবদ্ধ।
* যদি ব্যবহারকারীর প্রশ্নের কোনো নির্ভরযোগ্য উত্তর সংরক্ষিত ফাইলে থাকে, তবে দলীলসূত্রসহ উত্তরটি প্রদর্শিত হবে।
* **যদি সংরক্ষিত ডেটায় পর্যাপ্ত তথ্য না থাকে**, তবে সিস্টেম কোনো কৃত্রিম বা অনুমিত উত্তর তৈরি করবে না, বরং দ্ব্যর্থহীনভাবে প্রদর্শন করবে:
  > **"এই প্রশ্নের উত্তর দেওয়ার জন্য মাকতাব আল হিদায়াহর সংরক্ষিত তথ্যভাণ্ডারে পর্যাপ্ত তথ্য পাওয়া যায়নি।"**
